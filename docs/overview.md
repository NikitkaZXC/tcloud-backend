# Обзор

tcloud складывает фото, видео, аудио и GIF в приватные каналы Telegram через пользовательский аккаунт
(Telethon) и даёт к ним REST API. Ролей и пользователей нет: один владелец, один `X-API-Key`.

## Словарь

| Термин | Что это |
|---|---|
| **Хранилище** | приватный канал Telegram. В БД — только наш UUID и `tg_chat_id`, название, описание и фото живут в Telegram |
| **Путь** | `tcloud/{uuid хранилища}/{папки}/{имя}`; папки существуют только в БД |
| **Файл** | одно сообщение в канале. В подписи — токен `#tc<uuid без дефисов>` для поиска внутри Telegram |
| **Задача** | одна загрузка: стадии `receiving → scanning → uploading_tg → done/failed` |
| **Пачка** | до 100 задач, созданных одним `POST /api/uploads/batch`, с общим прогрессом |

## Главные правила

- Все наши id — UUID (v7 — растут во времени, индексы не фрагментируются). Числа — только id Telegram.
- `file_id` Telegram не храним: он меняется, а `file_reference` протухает. Храним `chat_id` + `message_id`,
  при скачивании сообщение запрашивается заново.
- Принимаем только медиа, тип определяется по содержимому. Файлы никогда не исполняются.
- Лимит файла — 2 ГБ, с Premium 4 ГБ; Premium проверяется автоматически.
- Сервис работает в одном процессе: очередь загрузок, прогресс и паузы живут в его памяти.
